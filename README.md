# My Express App

This is a simple Express application built with TypeScript.

## Prerequisites

- Node.js (version 14 or higher)
- npm (Node package manager)

## Installation

1. Clone the repository:

   git clone <repository-url>

2. Navigate to the project directory:

   cd my-express-app

3. Install the dependencies:

   npm install

## Configuration

The project is configured using TypeScript. The `tsconfig.json` file contains the necessary compiler options.

## Running the Application

To start the application in development mode, use the following command:

npm run start

This will compile the TypeScript files and start the Express server.

## Building the Application

To build the application for production, run:

npm run build

This will compile the TypeScript files into JavaScript.

## Routes

The application has a root route that can be accessed at:

http://localhost:3000/
